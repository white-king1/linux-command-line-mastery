# Linux Command Line Mastery

## Project Overview
Hands-on practice project covering Linux file management, navigation, system monitoring, networking, pipes, and shell scripting.

## Command List
- **Files:** touch, cp, mv, rm, cat, head, tail, less, find, grep
- **Navigation:** pwd, cd, mkdir -p
- **System:** ps aux, top, df -h, free -m, uptime, chmod, sudo
- **Networking:** ping, ip addr, ss -tuln
- **Pipes/redirects:** |, >, >>, 2>
- **Scripting:** variables, conditionals, loops, chmod +x

## Key Concepts Learned
- **Package Management:** Used `apt` to install and manage software on Ubuntu.
- **Permissions:** Learned how to use `chmod` (numeric and symbolic) to secure files. `700` means owner has full access, others have none.
- **System Monitoring:** Learned the difference between static process views (`ps aux`) and live views (`top`), plus how to check disk (`df`) and memory (`free`).
- **Pipes & Redirection:** Used `>` to overwrite, `>>` to append, and `|` to chain commands together for filtering.

## Tools Installed
- `tree`: Used for visualizing directory structures.
