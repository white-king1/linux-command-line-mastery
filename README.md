# Linux Command Line Mastery

## Project Overview
Hands-on practice project covering Linux file management, navigation, system monitoring, networking, pipes, and shell scripting.

## Command List
- **Files:** touch, cp, mv, rm, cat, head, tail, less, find, grep
- **Navigation:** pwd, cd, mkdir -p
- **System:** ps aux, top, df -h, free -m, uptime, chmod, sudo
- **Networking:** ping, ip addr, ss -tuln
- **Pipes/redirects:** |, >, >>, 2>
- **Scripting:** variables, conditionals, loops, chmod +x
